# Roadmap

This roadmap is intentionally simple.

Each phase should produce a reusable capability rather than just another model.

---

# Phase 0 — Data Foundation

Goal:

Build a clean, reproducible soccer dataset.

Deliverables:

- Download historical data
- Standardize schema
- Validate data quality
- Store processed dataset
- Version datasets

Success:

A single command rebuilds the dataset from scratch.

---

# Phase 1 — Market Understanding

Questions:

- How calibrated are bookmaker probabilities?
- Where are they systematically wrong?
- How do leagues differ?
- How does calibration change over time?

Deliverables:

- Calibration reports
- Bias analysis
- Baseline benchmarks

---

# Phase 2 — Prediction

Questions:

- Can we improve upon market probabilities?
- Which information adds predictive value?

Potential inputs:

- Team strength
- Elo
- Injuries
- Rest
- Weather
- Travel
- Player availability
- Market movement

---

# Phase 3 — Edge Validation

Build a robust backtesting framework.

Questions:

- Does the strategy survive transaction costs?
- Does it generalize across seasons?
- Is the edge statistically significant?

---

# Phase 4 — Execution

- Paper trading
- Portfolio construction
- Position sizing
- Risk management
- Automation

---

# Phase 5 — Generalization

Expand beyond soccer.

Possible directions:

- Other sports
- Kalshi
- Polymarket
- Financial prediction markets
- Cross-market arbitrage
- Market microstructure

---
